# Wave 3 copy repin

`atum-design.lock` now pins public `atum-platform/atum-desktop`
`055bd491eacc6df9223f6ef4ceaaf51a0ca80078` (atum-desktop#26, merged to desktop
`main`), manifest `dfeed62097bea25fa62efd5450c9ac592009d4656dffe21d7d909a6328ff9fc1`.
It replaces the wave 1 pin `c14d74a1`. The commit is the wave 3 phone copy export
in five locales: the AC, AS, TS and HC strings the wave 3 ports were coded against.

## What changed

Vendored export files and the lock (`Localizable.xcstrings`,
`copy-contract.json`, `manifest.json`, `phone-copy-map.json`,
`fixtures/playground.json`), plus the regenerated prototype catalog fixture.
No Swift source changes.

- 361 keys added, 3 removed. Desktop removed
  `mobileDeviceCopy.walletHistoryRows0Label` ("Demo task"),
  `walletHistoryRows1Label` ("Demo credit") and `packLayoutRows0Detail` ("…await
  owner product decisions") on purpose: they are placeholders that could leak
  (desktop `c8ebb9caf`, EX-ST-RM). No Swift source reads them, but the prototype
  catalog fixture did, so `PrototypeCatalogTests` failed with `missingKey`.
- `ios/Sources/AtumPrototype/Fixtures/native-catalog.json` is regenerated by
  `scripts/generate-native-catalog.py` from the private approved source
  (`atum-mobile` `docs/design/screen-catalog.json`), edited on private branch
  `chore/catalog-drop-placeholders` to match: proposals 160, 161 and 163 removed,
  the wallet-history study screen has no rows, and the Proton pack row has no
  detail. The generator's `--check` equality holds against that source. The
  private branch must merge with (or before) this repin so the source and the
  fixture's `sourceSHA256` (`1b5fc50a…`) agree.
- Every `*PendingCopy` table reads the export first, so the newly pinned keys
  now show the desktop export's wording. No call site changes.
- `tests/test_copy_keys_in_pin.py`: removed the 14 `PENDING` entries the pin now
  carries (person-info panel table, `assistantCardCopies.routineCount`,
  `model-picker-copy.COPY.subscriptions`). Four stay pending.

## Known gap (pre-existing, not a regression)

`test_copy_keys_in_pin.py` is not in CI and already failed on main: 171 key
literals were missing from the `c14d74a1` pin. After this repin, 74 remain, and
none is newly missing. They are all behind `PendingCopy` fallbacks or
`contains` guards: `TeamSpacePendingCopy` (34), `TeamSpaceThreadsPendingCopy`
(25), `TeamSpaceWave3PendingCopy` (8), `AppPanelPages` (6) and
`desktop.matrixShell.mainAgent` (HomeScreen, wave 1 follow-up). They need a
further desktop export before the test can go green and join CI.
